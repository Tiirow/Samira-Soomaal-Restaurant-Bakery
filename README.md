# 🍽️ Samira Soomaal Restaurant & Bakery

Welcome to the official website project for **Samira Soomaal Restaurant & Bakery** — a modern, professional, and responsive restaurant website designed to present the restaurant's food, bakery products, special offers, locations, and contact information in a clean and attractive way.

The website combines a modern user interface with a Somali-inspired restaurant identity, making it easy for customers to explore the menu, discover special deals, find restaurant locations, and learn more about Samira Soomaal Restaurant & Bakery.

---

## 🌟 About the Project

**Samira Soomaal Restaurant & Bakery** is a frontend web project created to provide a professional online presence for a restaurant and bakery business.

The website is designed with a strong focus on:

- 🎨 Modern and attractive design
- 📱 Responsive layout for all screen sizes
- 🍴 Restaurant menu presentation
- 🥐 Bakery product presentation
- 🔥 Special offers and deals
- 📍 Restaurant locations
- 📞 Contact information
- ⚡ Fast and simple user experience
- 🇸🇴 Somali restaurant identity

The main goal is to create a website that is easy to use, visually appealing, and suitable for both desktop and mobile users.

---

## ✨ Main Features

### 🏠 Professional Homepage

The homepage introduces Samira Soomaal Restaurant & Bakery with a modern hero section, restaurant branding, and important information for customers.

It provides visitors with a quick overview of the restaurant and helps them navigate to the most important sections of the website.

### 🍽️ Restaurant Menu

Customers can explore different food options available at the restaurant.

The menu is presented in a clean and organized way so visitors can easily understand the available products.

### 🥐 Bakery Section

The website also presents bakery products and gives customers a simple way to discover available bakery items.

This helps represent both sides of the business:

- 🍛 Restaurant
- 🥐 Bakery

### 🔥 Special Deals

The website includes special offers and deals designed to highlight selected products and provide customers with attractive options.

Deals can be used to promote:

- 🍔 Food combinations
- 🥤 Drinks
- 🍟 Special meals
- 🥐 Bakery products
- 🎉 Seasonal offers

### 📍 Restaurant Locations

Customers can find the available restaurant locations.

Current locations include:

- 📍 Waaberi, Mogadishu, Somalia
- 📍 Hodan, Mogadishu, Somalia
- 📍 Darusalam, Mogadishu, Somalia

This makes it easier for customers to identify the nearest restaurant location.

### 📞 Contact Information

### 📱 Responsive Design

The website is designed to work across different devices, including:

- 💻 Desktop computers
- 💻 Laptops
- 📱 Smartphones
- 📲 Tablets

The layout automatically adapts to different screen sizes.

### 🎨 Modern Visual Design

The website uses a professional visual identity based on:

- 🖤 Black

### ⚡ Simple Navigation

The website provides clear navigation so visitors can quickly move between important sections.

The goal is to make the website easy to understand even for users who are not technically experienced.

## 🛠️ Technologies Used

This project is built using modern frontend technologies.

### ⚛️ React

React is used to build the interactive user interface and organize the website into reusable components.

### 🎨 Tailwind CSS

Tailwind CSS is used for styling the website and creating a responsive layout.

### 🌐 HTML5

HTML5 provides the structure and semantic foundation of the website.

### 💻 JavaScript

JavaScript is used to provide functionality and interaction within the website.

### 🔤 Google Fonts

The website uses **Plus Jakarta Sans** to provide a modern and clean typography style.

### 📦 CDN

The project uses CDN resources for libraries such as React, ReactDOM, Babel, and Tailwind CSS.
